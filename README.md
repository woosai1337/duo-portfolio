# Два человека — портфолио

Статическое портфолио команды: сайты и Telegram-боты. Репозиторий публикуется через GitHub Pages из ветки `main`, папка `/ (root)`. Сборка и серверная часть не требуются.

## Демонстрационные проекты

- `projects/barbershop/` — FORM: услуги, демонстрация записи и ссылка на демо бота.
- `projects/form-bot/` — интерактивная имитация записи, переноса и отмены.
- `projects/beauty/` — MUSE: услуги, сравнение обработки портрета и демо записи.
- `projects/travel/` — ELSEWHERE: выбор направлений, программы и демо подбора.
- `projects/restaurant/` — ATELIER: меню, пространство и демо бронирования.
- `projects/architecture/` — ATELIER NORTH: выбор проектов и палитры материалов.
- `projects/coffee/` — EMBER: выбор вкуса и помола, демонстрационная корзина.
- `projects/florist/` — STILL BLOOM: подбор настроения и демонстрация сбора букета.

Все бренды и предложения вымышлены. Формы и бот не отправляют данные, не создают бронирования и не принимают оплату. Пользовательские контакты команды указаны на главной странице портфолио.

## Локальный просмотр

Из папки репозитория запустите:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Используйте сервер, а не открытие HTML-файла напрямую: так относительные ссылки работают как на GitHub Pages.

## Изображения и внешние ресурсы

Изображения в `assets/` с именами `*-editorial.jpg` и `ember-{morning,day,evening}.jpg` созданы генератором изображений для демонстрационных концептов. В отдельных проектах используются изображения, загружаемые с Unsplash; шрифты загружаются с Google Fonts. При отсутствии сети они могут не отображаться, а браузер использует запасные шрифты. При использовании демо для реального клиента проверьте права на все фотографии и замените вымышленные сведения реальными.
