# Два человека — портфолио

Статический сайт команды: сайты и Telegram-боты.

## Проекты

- FORM — барбершоп
- MUSE — beauty-студия
- ELSEWHERE — путешествия
- ATELIER — ресторан

Все примеры находятся в `projects/`. Это демонстрационные концепты вымышленных брендов; формы не отправляют данные.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Сборка не требуется.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.

Изображения загружаются с Unsplash, шрифты — с Google Fonts.
